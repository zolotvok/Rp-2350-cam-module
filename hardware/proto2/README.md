# proto2

Second prototype of the camera module, work in progress. It is built on [proto1](../proto1) and changes how the camera is attached and what the board can talk to.

## Planned changes

The schematic has a section for each of these:

- **Camera supply and clock on the board.** The support circuitry of the [Adafruit OV5640 breakout](https://github.com/adafruit/Adafruit-OV5640-Camera-Breakout-PCB) is moved onto the board: a 24-pin OV5640 module connector (X1), 2.8 V and 1.5 V regulators (TLV74328, TLV74315) and a 24 MHz oscillator. A solder jumper selects the camera clock: generated by the RP2350 (external XCLK, as on proto1) or taken from the oscillator (internal XCLK). Only the circuit comes from the breakout's schematic; the layout is not copied (see [NOTICE.md](../../NOTICE.md)).
- **CAN bus.** An MCP2515 CAN controller and an SN65HVD230 transceiver.
- **I²C pull-ups and level shifting.**
- **Additional LEDs.**

## Status

Snapshot from October 2026:

- **Schematic:** the new blocks are added; wiring them to the RP2350B is in progress.
- **PCB:** the layout has not been updated yet and is still the proto1 layout.
